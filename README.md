## 💬 对话记录要放哪里？
每个分类文件夹下都有 **`对话记录/`** 子文件夹。
- 按主题存到最相关分类的 `对话记录/`，文件名 `YYYY-MM-DD-主题.md`。
- 规范与模板见 [docs/工作/00-指南与规范/](docs/工作/00-指南与规范/)。
- 想让 AI 归档时，说「把这段对话整理归档」即可。

## 🔒 关于机密与隐私
- `docs/工作/13-内部机密合约/` 配置了 `.gitignore`，实际合约文件不会被提交。
- 请勿把账号密码、客户个资放入会提交的文件夹。

## 🔑 访问权限（重要）
本仓库应设为 **Private（私有）**，仅本人及授权协作者可访问。
- 设为私有：GitHub 仓库 → **Settings → General → Danger Zone → Change repository visibility → Private**
- 授权他人：**Settings → Collaborators → Add people**（仅添加你信任的人）
