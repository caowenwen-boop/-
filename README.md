# 日系品牌·中国线上销售 知识库 📚

本知识库用于整理与归档「日系品牌在中国市场的线上销售」相关的工作内容，包含遇到的问题、参考资讯、查询记录，以及与 AI 助手的对话记录；同时附带个人日语学习系统。

> 目的：把日常工作中零散的问题、资料、对话，按主题分类保存，方便日后查找与复用。

## 💬 对话记录要放哪里？

每个分类文件夹下都有一个 **`对话记录/`** 子文件夹。

- 把与工作相关的对话，按主题存到**最相关分类**的 `对话记录/` 里。
- 文件名格式：`YYYY-MM-DD-主题简述.md`（例：`2026-07-25-天猫国际保税仓入仓流程.md`）。
- 保存格式请参考 👉 [对话记录规范](docs/00-指南与规范/对话记录规范.md) 与 [模板](docs/00-指南与规范/对话记录模板.md)。

> 💡 想让 AI 帮你归档时，只要说：「把这段对话整理归档」，AI 会判断主题、选择对应文件夹、按模板生成文件。
