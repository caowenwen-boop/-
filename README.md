## 💬 對話紀錄要放哪裡？

每個分類資料夾底下都有一個 **`對話紀錄/`** 子資料夾。

- 把與工作相關的對話，依主題存到**最相關分類**的 `對話紀錄/` 裡。
- 檔名格式：`YYYY-MM-DD-主題簡述.md`（例：`2026-07-25-天貓國際保稅倉入倉流程.md`）。
- 保存格式請參考 👉 [對話紀錄規範](docs/00-指南與規範/對話紀錄規範.md) 與 [範本](docs/00-指南與規範/對話紀錄範本.md)。

> 💡 想讓 AI 幫你歸檔時，只要說：「把這段對話整理歸檔」，AI 會判斷主題、選擇對應資料夾、依範本產生檔案。

---

## 🔎 如何使用

1. **遇到問題／查資料** → 在對應分類寫下筆記或存入對話紀錄。
2. **找舊資料** → 依分類瀏覽，或用關鍵字搜尋整個 `docs/`。
3. **不確定放哪** → 先看該分類 README 的「本分類收錄範圍」，或放進最接近的分類，日後再調整。
