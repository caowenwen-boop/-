# 建立日系品牌中國線上銷售知識庫

- **日期**：2026-07-25
- **分類**：00-指南與規範
- **標籤**：#知識庫 #分類架構 #歸檔規範

---

## 背景 / 問題
工作內容是「日系品牌在中國市場的線上銷售」。日常會遇到各種問題、參考資訊、需要查詢的事項，以及與 AI 的對話，希望有一套**細分類的文件系統**，並能把聊天內容對應保存到相應資料夾。

## 結論 / 解法 ⭐
建立 `docs/` 知識庫，依主題分為 00–12 共 13 個分類，每個分類底下都有 `對話紀錄/` 子資料夾：

1. **00 指南與規範**：使用說明、分類原則、對話紀錄規範與範本
2. **01 電商平台**：天貓國際 / 京東國際 / 抖音 / 小紅書 / 其他平台
3. **02 跨境電商政策與法規**
4. **03 品牌與授權**
5. **04 行銷推廣**：直播帶貨 / 達人KOL / 付費廣告 / 內容營銷 / 私域流量
6. **05 店鋪營運**
7. **06 供應鏈與物流**
8. **07 數據分析**
9. **08 客服與售後**
10. **09 財務與合規**
11. **10 市場與競品**
12. **11 日本總部對接**
13. **12 常見問題FAQ**

歸檔方式：把對話依主題存到最相關分類的 `對話紀錄/`，檔名 `YYYY-MM-DD-主題.md`，格式套用範本。

## 重點整理
- 分類原則：依主題不依時間、就近原則、平台專屬 vs 通用功能分開。
- 想歸檔時對 AI 說「把這段對話整理歸檔」即可，AI 會判斷分類並套範本產檔。
- 本檔即為第一個示範紀錄。
