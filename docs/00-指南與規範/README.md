# 00 · 指南與規範

本資料夾說明整個知識庫要怎麼用、內容怎麼分類、對話紀錄怎麼保存。

## 本分類收錄範圍
- 知識庫的使用說明
- 分類原則與命名規則
- 對話紀錄的保存規範與範本

## 檔案清單
- [對話紀錄規範.md](對話紀錄規範.md) — 對話怎麼歸檔、命名、放哪裡
- [對話紀錄範本.md](對話紀錄範本.md) — 直接複製使用的 Markdown 範本

## 分類原則
1. **依主題，不依時間**：先問「這件事屬於哪個業務主題」，再決定放哪個分類（00–12）。
2. **就近原則**：一份內容若橫跨多個主題，放進**最主要**的那個分類，其餘分類可留一行連結指過去。
3. **平台專屬 vs 通用**：只跟某平台有關（如天貓後台某功能）→ 放 `01-電商平台/該平台/`；跨平台通用的做法（如直播腳本模板）→ 放對應功能分類（如 `04-行銷推廣/直播帶貨/`）。

## 命名規則
- 一般筆記：`主題.md`（例：`保稅倉入倉流程.md`）
- 對話紀錄：`YYYY-MM-DD-主題簡述.md`（例：`2026-07-25-抖音小店入駐資質.md`）
- 資料夾與檔名使用繁體中文即可；平台/專有名詞（天貓、京東、抖音、小紅書）沿用官方簡體寫法。
