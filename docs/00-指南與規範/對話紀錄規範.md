# 對話紀錄保存規範

用來把工作中有價值的對話（尤其與 AI 助手的問答）整理歸檔，方便日後查找複用。

## 一、放在哪裡
存到**最相關分類**底下的 `對話紀錄/` 子資料夾。

| 對話主題舉例 | 建議存放位置 |
|--------------|--------------|
| 天貓國際後台某功能怎麼設定 | `docs/01-電商平台/天貓國際/對話紀錄/` |
| 保稅倉清關卡關怎麼辦 | `docs/02-跨境電商政策與法規/對話紀錄/` |
| 直播腳本、達人合作報價 | `docs/04-行銷推廣/直播帶貨/對話紀錄/` 或 `達人KOL/對話紀錄/` |
| 雙11 活動排期規劃 | `docs/05-店鋪營運/對話紀錄/` |
| 給日本總部的月報怎麼寫 | `docs/11-日本總部對接/對話紀錄/` |

> 若一段對話橫跨多主題，選最主要的一個存放即可。

## 二、檔名規則
```
YYYY-MM-DD-主題簡述.md
```
- 例：`2026-07-25-天貓國際保稅倉入倉流程.md`
- 主題簡述用幾個關鍵字，能一眼看懂即可。

## 三、內容格式
請套用 [對話紀錄範本.md](對話紀錄範本.md)，至少包含：
1. **標題與日期**
2. **背景／要解決的問題**
3. **結論／解法**（最重要，放前面）
4. **對話重點或全文**
5. **待辦／後續**（如有）
6. **標籤**（方便搜尋）

## 四、讓 AI 幫你歸檔
直接對 AI 說：

> 「把上面這段對話整理歸檔」

AI 會：判斷主題 → 選對應分類資料夾 → 依範本產生檔案 → 存到 `對話紀錄/` 底下並命名。
你也可以指定分類：「歸檔到 04-行銷推廣」。
