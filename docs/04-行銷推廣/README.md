# 04 · 行銷推廣

跨平台通用的行銷、推廣、流量獲取相關內容。

## 本分類收錄範圍
- 各類行銷玩法的策略、腳本、報價、覆盤

## 子分類
| 子分類 | 內容 | 連結 |
|--------|------|------|
| 直播帶貨 | 直播排期、腳本、話術、選品、覆盤 | [直播帶貨/](直播帶貨/) |
| 達人KOL | 達人/博主/買手合作、報價、寄樣、結算 | [達人KOL/](達人KOL/) |
| 付費廣告 | 直通車、引力魔方、萬相台、巨量千川、聚光等投流 | [付費廣告/](付費廣告/) |
| 內容營銷 | 圖文/短視頻/種草內容、主圖詳情頁、違禁詞 | [內容營銷/](內容營銷/) |
| 私域流量 | 微信社群、會員、CRM、複購 | [私域流量/](私域流量/) |
