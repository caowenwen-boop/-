# 🏠 日本福冈 · 买房档案

个人用。关注福冈（尤其东区）房价，记录看房偏好、决策思考、市场信息。

## 我的现状与偏好（2026-07 起）
- **地点**：日本福冈，工作/生活在福冈。
- **心仪区域**：**东区 照り葉（アイランドシティ / Island City）**——之前很喜欢那边的房子。
- **纠结点**：买**公寓(マンション)** 还是 **一户建(一戸建)**？
- **购买条件（自己定的底线）**：
  - 公寓 → 只考虑**二手**，且**楼龄 10年以内**
  - 一户建 → 只考虑**全新**
- **目的**：以自住为主（待补充：是否也考虑保值/将来出租转售）。

## 待明确（会影响决策，逐步补）
- [ ] 预算 / 首付 / 房贷额度与年限
- [ ] 打算持有几年（短中长期）
- [ ] 通勤地点与可接受通勤时间（照り葉离天神/博多约30–40分）
- [ ] 家庭人数 / 是否有小孩（学区）
- [ ] 是否介意每月管理费+修缮积立金上涨（公寓）/ 自己维护房子（一户建）
