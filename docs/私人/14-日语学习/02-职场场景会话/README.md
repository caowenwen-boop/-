# 02 · 职场场景会话

按「真实工作场景」积累对话，学了马上能用。

## 收录范围（建议逐个场景积累）
- 打招呼 / 自我介绍（挨拶・自己紹介）
- 向上司汇报（報告・連絡・相談＝報連相）
- 请假 / 迟到（休暇・遅刻の連絡）
- 拜托同事 / 催进度（依頼・催促）
- 道歉 / 认错（謝罪）
- 确认 / 反问（確認）
- 开会发言（会議での発言）
- 接待 / 电话（来客・電話）

## 每个场景建议记录格式
- 场景说明（对谁、什么情况）
- 对话（日文 + 假名 + 中文）
- 可替换的关键句
- 注意点（失礼/得体）
