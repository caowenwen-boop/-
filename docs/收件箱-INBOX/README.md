# 📥 收件箱 · INBOX（思考与输入捕捉区）

这里是**万物先落地**的地方。不管能不能分类，先记下来。

## 这个文件夹是干嘛的
- 记录**你说过的内容、提出的疑问、临时的想法**——哪怕当下无法归类。
- 沉淀你的**思考回路**：为什么这么想、纠结过什么、最后怎么决定的。
- 作为 AI 的「记忆入口」：与你聊过的东西先进这里，之后再判断要不要整理成正式文档、归到哪个分类。

> 定位：`工作/`、`私人/` 是**整理好的成品**；本 INBOX 是**原始素材与思考流水**。两者互补。

## 怎么运作
1. **随手记**：任何对话、疑问、灵感 → 追加到当月的 `思考记录-YYYY-MM.md`。
2. **定期梳理**：当某条内容成熟、可归类 → 整理进 `工作/` 或 `私人/` 对应分类，并在原条目标注「已归档到 → xxx」。
3. **不强求分类**：分不了类就留在这里，不丢失即可。

## 让 AI 配合
- 「把刚才这段也记到收件箱」→ 我把要点追加进当月流水。
- 「收件箱里关于 XX 的整理一下」→ 我把成熟内容归类到正式分类。
