## 🤖 怎么用 AI 学日语（高效用法）
把 AI 当成随身日语老师，常用指令：

- 「帮我把这句中文翻成**商务日语**，并解释用了什么敬语」
- 「这封日语邮件帮我看看有没有失礼的地方，并给出更自然的说法」
- 「解释这个语法：〜ていただけますでしょうか，并给3个职场例句」
- 「这个场景（跟上司请假）帮我做一段对话，附假名和中文」
- 「把今天这些生词整理成生词本格式」

学完后说一句「**归档到日语学习**」，我会按分类存进对应 `对话记录/` 或生词本。

## 📌 学习建议
1. **少而勤**：每天 10–15 分钟，重点在坚持（用 05-每日学习记录 打卡）。
2. **工作即教材**：把每天工作中看不懂的日语邮件/词，随手丢进生词本。
3. **敬语优先**：日企最看重礼貌得体，先把邮件和寒暄的敬语练熟。
