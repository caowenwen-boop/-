# 01 · 商务日语

日企职场最核心的部分：敬语、商务邮件、电话与会议用语。

## 收录范围
- **敬语（敬語）**：尊敬语、谦让语、丁宁语的区分与常用变换
- **商务邮件（ビジネスメール）**：开头寒暄、正文、结尾、常用句型模板
- **电话应对（電話応対）**：接打电话、转达、留言
- **会议用语（会議）**：发言、确认、提问、附和（相槌）

## 建议先掌握的高频敬语
| 普通 | 尊敬语（对方动作） | 谦让语（自己动作） |
|------|------|------|
| する | なさる | いたす |
| 言う | おっしゃる | 申す / 申し上げる |
| 行く/来る | いらっしゃる | 伺う / 参る |
| 見る | ご覧になる | 拝見する |
| 食べる | 召し上がる | いただく |

## 邮件常用句（开头/结尾）
- 开头：`お世話になっております。` / `いつも大変お世話になっております。`
- 拜托：`〜していただけますでしょうか。`
- 结尾：`何卒よろしくお願い申し上げます。`
