## 邮件万能句（起步）
| 场景 | 日语 | 中文 |
|------|------|------|
| 开头 | お世話になっております。 | 承蒙关照。 |
| 自报 | ○○社の△△と申します。 | 我是○○公司的△△。 |
| 拜托 | 〜していただけますでしょうか。 | 能否请您……？ |
| 确认 | ご確認のほど、よろしくお願いいたします。 | 烦请确认。 |
| 道歉 | ご迷惑をおかけし、申し訳ございません。 | 给您添麻烦了，非常抱歉。 |
| 催促 | 度々恐れ入りますが、〜 | 屡次打扰，不好意思…… |
| 结尾 | 何卒よろしくお願い申し上げます。 | 万望关照。 |
