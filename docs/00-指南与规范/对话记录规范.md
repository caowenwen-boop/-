# 对话记录保存规范

用来把工作中有价值的对话（尤其与 AI 助手的问答）整理归档，方便日后查找复用。

## 一、放在哪里
存到**最相关分类**下的 `对话记录/` 子文件夹。

| 对话主题举例 | 建议存放位置 |
|--------------|--------------|
| 天猫国际后台某功能怎么设置 | `docs/01-电商平台/天猫国际/对话记录/` |
| 保税仓清关卡关怎么办 | `docs/02-跨境电商政策与法规/对话记录/` |
| 直播脚本、达人合作报价 | `docs/04-营销推广/直播带货/对话记录/` 或 `达人KOL/对话记录/` |
| 双11 活动排期规划 | `docs/05-店铺运营/对话记录/` |
| 给日本总部的月报怎么写 | `docs/11-日本总部对接/对话记录/` |
| 某个日语表达怎么用 | `docs/14-日语学习/对应子分类/对话记录/` |

> 若一段对话横跨多主题，选最主要的一个存放即可。

## 二、文件名规则
```
YYYY-MM-DD-主题简述.md
```
- 例：`2026-07-25-天猫国际保税仓入仓流程.md`
- 主题简述用几个关键词，能一眼看懂即可。

## 三、内容格式
请套用 [对话记录模板.md](对话记录模板.md)，至少包含：
1. **标题与日期**
2. **背景／要解决的问题**
3. **结论／解法**（最重要，放前面）
4. **对话重点或全文**
5. **待办／后续**（如有）
6. **标签**（方便搜索）

## 四、让 AI 帮你归档
直接对 AI 说：

> 「把上面这段对话整理归档」

AI 会：判断主题 → 选对应分类文件夹 → 按模板生成文件 → 存到 `对话记录/` 下并命名。
你也可以指定分类：「归档到 04-营销推广」。
