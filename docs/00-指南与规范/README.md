# 00 · 指南与规范

本文件夹说明整个知识库怎么用、内容怎么分类、对话记录怎么保存。

## 本分类收录范围
- 知识库的使用说明
- 分类原则与命名规则
- 对话记录的保存规范与模板

## 文件清单
- [对话记录规范.md](对话记录规范.md) — 对话怎么归档、命名、放哪里
- [对话记录模板.md](对话记录模板.md) — 直接复制使用的 Markdown 模板

## 分类原则
1. **按主题，不按时间**：先问「这件事属于哪个业务主题」，再决定放哪个分类（00–14）。
2. **就近原则**：一份内容若横跨多个主题，放进**最主要**的那个分类，其余分类可留一行链接指过去。
3. **平台专属 vs 通用**：只跟某平台有关（如天猫后台某功能）→ 放 `01-电商平台/该平台/`；跨平台通用的做法（如直播脚本模板）→ 放对应功能分类（如 `04-营销推广/直播带货/`）。

## 命名规则
- 一般笔记：`主题.md`（例：`保税仓入仓流程.md`）
- 对话记录：`YYYY-MM-DD-主题简述.md`（例：`2026-07-25-抖音小店入驻资质.md`）
- 文件夹与文件名统一使用简体中文；平台/专有名词沿用官方写法（天猫、京东、抖音、小红书）。
