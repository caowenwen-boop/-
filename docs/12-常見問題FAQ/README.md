# 12 · 常見問題 FAQ

反覆出現、需要快速查閱的問題與標準答案。當某個問題被問到第二、三次，就整理進這裡。

## 使用方式
- 每個常見問題建一個檔案，或彙整成主題清單。
- 檔名：`主題-FAQ.md`（例：`保稅倉入倉-FAQ.md`）。
- 答案要精簡、可直接照做；細節可連結到對應分類的詳細紀錄。
