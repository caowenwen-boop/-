# 02 · 跨境電商政策與法規

跨境電商相關的政策、法規、通關與備案，是日系品牌進中國的合規基礎。

## 本分類收錄範圍
- **跨境模式**：保稅倉進口、海外直郵、一般貿易的差異與適用
- **稅務**：跨境電商綜合稅、行郵稅、年度/單次交易限額
- **正面清單**：可跨境進口的商品目錄
- **通關清關**：三單合一（訂單/支付單/物流單）、卡關處理
- **產品備案 / 註冊**：
  - 化妝品：普通/特殊化妝品備案、NMPA
  - 食品/保健品：藍帽子、進口食品標籤
  - 其他日系常見品類的准入
- **法規變動**：政策更新、口岸公告
