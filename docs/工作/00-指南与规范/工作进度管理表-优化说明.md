# 工作进度管理表 · 优化说明

- **日期**：2026-08-05
- **原表**：Google Sheet「Sakura_工作内容管理_202608」（国内办公室各岗位工作进度）
- **产出**：`工作进度管理表-优化模板.xlsx`（同目录，可导入 Google Sheets）

## 一、原表为什么"看不出进度"
现表是**日历块布局**：每个日期（08/03、08/04…）是一个小方块（序号/部门/工作内容/进度下拉），横向铺 4 块、纵向堆很多排。问题：
1. **状态散落在几十个格子里**，没有任何汇总 → 无法一眼知道"整体完成多少"。
2. **不能筛选排序**（是固定网格不是列表）→ 看不了"某人所有任务""所有未完成"。
3. **无延期预警** → 计划完成日过了也不提示。
4. **两列"进度"含义重复**、颜色标签(日本/樱拓/樱启)只是部门，没进入统计。
5. 每人一个 tab（小裴/咩咩/张姐/毛毛/Alice/柚子），**无法跨人汇总**全员进度。

## 二、优化后的结构（3+1 sheet）
**① 任务清单**（核心：扁平表，一行一个任务）
`日期 / 星期(自动) / 部门 / 负责人 / 分类 / 工作内容 / 状态 / 计划完成日 / 实际完成日 / 是否延期(自动) / 备注`
- 部门·负责人·分类·状态都是**下拉**；
- **状态自动上色**：已完成🟢 / 进行中🟡 / 未开始⚪ / 已延期🔴 / 搁置🔵——进度一眼可见；
- **延期自动预警**：状态非"已完成"且计划完成日已过 → 标 ⚠️延期，**整行淡红**；
- 可**筛选排序**：按负责人筛=看某人全部任务，按状态筛=看所有未完成/延期。

**② 进度看板**（全自动，不用手算）
- **总体完成率**（带进度条）+ 各状态数量（带条形）；
- **按负责人** 完成率（带进度条）——谁快谁慢一眼看出；
- **按部门** 完成率；
- **延期任务数**预警。

**③ 说明** / **选项**（下拉维护）。

## 三、怎么用
1. **导入 Google Sheets**：文件→导入→上传→"新建/替换表格"。下拉、颜色、进度条基本保留（个别条件格式若没跟过来，按「说明」页重设一次）。
2. 每天填「任务清单」一行一个任务，选好状态；看板自动更新。
3. 看单人进度：任务清单→创建筛选器→按负责人筛。

## 四、备选方案
若坚持保留现有日历块布局，可改用 **Google Apps Script** 在原表加一个"进度看板"tab 自动统计——但日历块格式解析较脆弱，**推荐直接采用本模板的扁平清单**，长期更好维护。
