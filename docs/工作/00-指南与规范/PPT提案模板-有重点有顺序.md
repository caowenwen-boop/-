# PPT 提案标准 · 「有重点、有顺序」

> 约定来源：2026-08-06 用户同事对差异化方案 PPT 的重新优化版（QF 8–11月 小红书笔记种草方案 v4）。
> **以后给用户做的所有提案类 PPT，都按本模板的骨架与规矩来。** 建 PPT 前先按「快速自检」核对一遍。

---

## 一、核心原则（记住这 4 句）

1. **结论先行**：第 2 页就把"要说的三件事"讲完，后面全是展开与证据。别让品牌方翻到最后才看到结论。
2. **有顺序**：页与页是一条**因果链**——现状 → 真因(假设) → 打法 → 内容 → 关键词 → 预算/排期。每页承接上一页。
3. **一页一个重点**：每页只讲一件事，标题就是这页的**结论句**（不是"人群分析"这种名词，而是"高互动人群集中在 L5–L4"这种判断句）。
4. **每个数字都有出处**：页脚标 `数据来源` 或 `假设`；是推测就老实写"▼ 假设/待验证"，不伪装成事实。

---

## 二、标准页序（骨架）

| 页 | 作用 | 必备要素 |
|----|------|----------|
| **P1 封面** | 一句话说清这次要干什么 | 标题 + **一行主张**（"把预算全部投在双11之前"式的取舍句）+ 日期 + 用途标注（如"提案・品牌确认用"）|
| **P2 结论** | 先说三个要点 | `01 现状` / `02 真因(假设)` / `03 打法`，每条：**粗体小标题 + 一句支撑 + ▼ 脚注**标明是事实还是假设 |
| **P3 ①人群** | 谁值得投 | **大数字块**（如 71.4% / 76.4% / 82.8%）+ L5–L1 分层 + 底部一句 takeaway + `数据来源` |
| **P4 ②诊断(假设)** | 为什么是现在这样 | 因果链，用 **▼ 箭头**串 3–5 步；标"假设" |
| **P5–P6 ③内容设计** | 具体怎么做内容 | 按「起点」分类表（痛点/品类/竞品/品牌/旅行=不做），讲清做什么、不做什么 |
| **P7 ④关键词** | 合规怎么把握 | **合规三档表**：✅可用 / ⚠️软化 / ❌禁用 |
| **P8 ⑤预算** | 钱怎么分 | 达人层级 × 单价 × 篇数 × 预算 表，顶部标总预算；单价标"假设/按报价确认"，避免重复计算的口径说明 |
| **P9 ⑤排期** | 什么时候做 | 月度节奏表（预算/节奏/重点动作/量），配一句时间逻辑（如"种草到搜索有 1–2 月滞后"）|
| **P10 ⑥验证** | 怎么判断成败 | KPI 表 `现状 / 中间节点 / 终点` 三列；**第一行放先行指标**（人群/兴趣构成先变，主 KPI 才会动），点明"不用直接 ROAS 判断，买的是搜索与人群资产" |
| **P11 执行** | 分阶段怎么落地 | **A/B/C 三栏**时间轴（验证 → 放大 → 铺满），每栏列具体动作；点明"先验证假设，再决定往哪加钱" |
| **P12 本次需确认** | 要品牌方拍板什么 | 收尾页，**编号列 3–4 个确认事项**（问题认识/内容方向/预算节奏/监测），最后一句点明窗口/紧迫性 |

> 页数可增减，但**顺序骨架不变**：结论 → 人群 → 诊断 → 内容 → 关键词 → 预算排期 → **验证 → 执行 → 需确认**。
> 尾三页（验证/执行/需确认）是提案能被"拍板"的关键：先讲**怎么证明有效**，再讲**分几步做**，最后**明确要对方点头的几件事**——别让品牌方看完不知道要决定什么。

---

## 三、每页统一格式（版式规矩）

- **编号章节**：正文页用 ① ② ③ ④ ⑤ 标序号，让读者永远知道走到第几步。
- **粗体结论式标题**：标题写"判断/结论"，不写"XX分析"。
- **大数字块**：关键数据放大做视觉锤（一页 1–3 个大数字，不堆表）。
- **底部一句 takeaway**：每页最下面一行黑体，把这页浓缩成一句"所以呢"。
- **页脚脚注**：`数据来源：…` 或 `假设：…`，区分事实与推测。
- **▼ 标记**：凡是假设、待验证、因果推断，用 ▼ 明确标出。
- **诚实标注**：样本小就写"n=29，样本小仅作方向性信号"；单价/汇率是估值就写"假设值，按报价确认"；避免重复计算的口径要写清（如"笔直坑位计入直播线，不重复计算"）。宁可老实说"这是假设、8月实测验证"，也不把推测写成结论。

## 四、快速自检（建 PPT 前逐条打勾）

- [ ] 封面有没有**一行主张**（一句话能说清取舍）？
- [ ] 第 2 页是不是**已经把结论讲完**（三个要点）？
- [ ] 页与页是不是一条**因果链**、顺序对不对？
- [ ] 每页标题是不是**结论句**、是不是**只讲一件事**？
- [ ] 关键数据有没有做成**大数字块**？
- [ ] 每页底部有没有**一句 takeaway**？
- [ ] 每个数字有没有标 **数据来源/假设**？
- [ ] 有没有**合规三档**（涉及关键词/文案时）？
- [ ] 假设有没有用 **▼** 老实标出来（不硬编成事实）？
- [ ] 有没有**验证页**（怎么判断成败、先行指标在最前）？
- [ ] 有没有**执行页**（分阶段 A/B/C 落地动作）？
- [ ] 有没有**收尾"需确认"页**（明确要品牌方拍板的几件事）？

## 五、和「手批分析草稿」风格的分工

- **对内的分析/复盘**（如 100 篇笔记复盘、10 差异点）→ 用**手批分析草稿**风格（结论先行＋观察→判断＋真实数据图＋墨批圈注），要"像人真的坐下来做分析"。
- **对外/对品牌方的提案** → 用**本 PPT 模板**（有重点、有顺序、结论先行、编号章节、大数字、底部 takeaway、数据来源标注）。

两者内核一致：**结论先行 + 数字有出处 + 不装 AI 腔**。
