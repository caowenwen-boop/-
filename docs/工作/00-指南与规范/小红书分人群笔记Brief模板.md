# 小红书·分人群笔记 Brief 模板（用户认可版）

> 来源：用户 2026-10 提供的样例 `皇后的秘密VC100面膜·金色款·学生党/油皮` Brief（PDF `b81a900d`），确认为**今后做笔记 Brief 的标准模型**。
> 适用：代运营（Quality1st 面膜）及自有品牌的**达人/KOC 单篇笔记派单 Brief**。
> 特点：**按"人群①②③…"拆分**，每个人群单独一份；字段固定、结论先行、功效一律软化、附合规禁区。

---

## 一、固定字段结构（每份一个人群，照这些字段填）

| 字段 | 填什么 |
|---|---|
| **标题行** | `产品款式 + 人群②XXX（痛点关键词）+ 场景/形式`（如"前后对比"） |
| **内容方向** | 一句话说清：这个人群用这款产品，解决什么痛点、给什么方案（结论先行） |
| **内容结构** | 笔记的叙事链路：痛点触发 → 科普逻辑 → 使用演示（洁面后3分钟敷用）→ 体感 → 引导（测试/评论区报肤质） |
| **标题文案** | 给 3 条可选标题（含痛点词/人群词/实测感） |
| **话题要求** | 分三类标签：①痛点类 ②产品/品类 ③人群场景 |
| **封面要求** | 画面内容 + 自然露出产品 + 大字痛点文案 + 风格（如"清爽学生风"） |
| **文案参考（产品介绍）** | 商品词 / 核心卖点 / **功效（软化）** / 【卖点解说】一段话 |
| **禁忌人群/事项** | 肤质禁忌 + 使用注意 + **※禁用词清单**（替换成软化说法） |
| **建议关键词** | 品类 / 内容方向 / 人群 / 品牌 四组 |

---

## 二、样例（金色 VC100 面膜 · 人群② 学生党/油皮）

- **标题行**：金色款 皇后的秘密VC100面膜 ｜ 人群② 学生党/油皮（大毛孔·黑头·粗糙暗沉）前后对比
- **内容方向**：学生党、油皮的大毛孔/黑头/粗糙暗沉，怎么用金色VC面膜「清爽提亮 + 毛孔护理」，平价高频的日常护肤方案。
- **内容结构**：油皮大毛孔黑头痛点被触发 → 科普「维C+烟酰胺 毛孔护理与提亮」逻辑 → 洁面后3分钟敷用演示 → 毛孔细腻·清爽·提亮体感 → 提醒先测试、清爽护肤，引导评论区报肤质。
- **标题文案**：
  - 大毛孔黑头救星？学生党平价VC面膜实测
  - 油皮亲测｜3分钟毛孔护理+提亮
  - 换季暗沉粗糙，回购的VC面膜真实分享
- **话题要求**：
  - 痛点类：#毛孔护理 #黑头 #粗糙暗沉
  - 产品/品类：#面膜推荐 #日本面膜 #平价面膜 #DermaLaser #皇后的秘密
  - 人群场景：#学生党护肤 #油皮护肤 #换季护肤
- **封面要求**：年轻/学生真实场景，毛孔特写或敷面膜画面，自然露出金色面膜袋，配大字痛点文案如「毛孔护理」「3分钟提亮」，清爽学生风。
- **文案参考（产品介绍）**：
  - 商品词：皇后的秘密金色超级VC100面膜
  - 核心卖点：日本进口·4重复合维C ＋ 10%烟酰胺·3分钟高浓度集中
  - 功效（软化）：毛孔护理·提亮暗沉·细腻肤感
  - 【卖点解说】4重维C+10%烟酰胺护理毛孔外观、提亮匀净；3分钟清爽不闷；高服帖膜布贴合吸收；日本进口人气款。
- **禁忌人群/事项**：对维C衍生物过敏者勿用；痘痘破损处避开、面部有伤口暂停；敷后做好防晒。**※禁「收缩毛孔/去黑头/祛痘/美白」等宣称，用 毛孔护理/细腻肤感/提亮 替代。**
- **建议关键词**：品类=面膜推荐·平价面膜·日本面膜 ｜ 内容方向=毛孔护理·黑头·提亮 ｜ 人群=学生党护肤·油皮护肤 ｜ 品牌=DermaLaser·皇后的秘密

## 三、使用约定

- 以后做**面膜/护肤品类的达人派单 Brief**，默认套这个结构，**按人群拆份**。
- **功效一律软化**（见各品类红线）；每份底部必带「禁用词清单 + 软化替代」。
- 保健品（护眼丸等）另有更严红线（禁护眼/视力/防蓝光/功效/蓝帽子），套本结构时按保健品红线再收紧。
