## 一、整体结构

- **一个工作簿 = 1 张「汇总」sheet + 每月 1 张月度 sheet**
  - 汇总 sheet 命名：`汇总（8-12月）`（按实际季度/期间调整）
  - 月度 sheet 命名：`2026-08`、`2026-09`……（`YYYY-MM`）
- 汇总 sheet 的数字**全部由各月页自动联动**，不手动编辑。
- 全表**关闭网格线**（`showGridLines=False`）。

## 四、关键规范要点

1. **双口径（核心）**
   - **按付款月**：明细行放在「实际付款的月份」页；= 预实对比表口径。
   - **按投放月**：投放跨月时，在 `★投放月` 填实际投放月；用于判断投放效率。两者不一致属正常。
2. **配色（固定）**：主色深蓝 `#213349`（标题/表头，白字加粗）；合计行浅蓝 `#EFF4F9`；区块标题浅灰 `#EDEDEF` 加粗；正文白底黑字 10pt；关网格线。
3. **金额一律「税入」**，数字格式 `#,##0` 或 `#,##0.00`。
4. **区块编号**：大区块用 `一、二、`；汇总子块用 `■ ① ② ③`；标题式表达。

## 五、自动公式约定

| 用途 | 公式（以第5行/第18行为例） |
|---|---|
| 实际支出（预算总览 F 列） | `=SUMIF($C$18:$C$77,$A5,$G$18:$G$77)` |
| 差额（H 列） | `=IF(N(D5)=0,"",D5-F5)` |
| 执行率（I 列） | `=IF(N(D5)=0,"",F5/D5)` |
| 合计 | `=SUM(D5:D13)` |
| 投产比（明细 K 列） | `=IF(OR(N($J18)=0,N($G18)=0),"",$J18/$G18)` |

> 空值判断统一用 `N()` 防止 `#DIV/0!` 与空单元格报错。

## 六、汇总 sheet 结构（5 大区块）

| 区块 | 标题 | 说明 |
|---|---|---|
| ① | `■ ① 实际支出【按付款月·元】` | 各月页 F 列联动：`='2026-08'!F5` … 末列合计、并按科目 SUMIF 拆「站外种草(Red)」与「★无预算科目」 |
| ② | `■ ② 预算【按付款月·元】` | 各月预算联动 |

| ④ | `■ ④ 按投放月【该月实际投放的广告·元】※判断投放合理性看这里` | 按投放月口径 |
| ⑤ | `■ ⑤ 备注` | 口径说明（付款月/投放月/无预算科目等） |

- 汇总表头行：`费用类别 ｜ 各月份 ｜ 合计 ｜ 预实对比表科目`
- **冻结**：`A6`。
- 顶部注明：`※由各月页自动汇总，请勿编辑`。

## 七、明细字段填写口径
- `用途·合作条件`：如「20000保比roi为3」「6场直播，线上佣金25%」「（笔记1w软植入）+20% 讲解1场」。
- `直播产品`：填涉及的面膜色号（金色/黑银色/黑金色/蓝色/银色…）。
- `付款主体`：如 `Sakura`。
- `支付方式`：对公转账 / 直付达人 / …。
