## 一、lululun 爆文结构拆解（可复制公式）
从 Top15 + 维度数据提炼：

| 要素 | 规律 |
|------|------|
| **标题** | 地域信任(🇯🇵日本/药妆店) + 决策钩子(怎么选/不踩雷/一篇全搞定) + 价格心智(平价) + 品类(面膜) |

| **正文结构** | 痛点/需求 → 按肤质·需求分类 → 每款卖点+价格 → 使用建议 → 引导收藏 |

| **关键词** | 品牌词+品类词+功效词+场景地域词 |

## 四、Quality 1st 笔记蓝图（5类，可直接落地）
每类给：标题公式 / 封面 / 正文 / 图数 / 关键词 / 达人层级

**① A·选购攻略/合集（主力·蓄水引擎）**
- 标题：`日本面膜怎么选？提亮/毛孔/维稳一篇搞定`（合集里植入皇后的秘密VC精华）
- 封面：多款按需求分类摆拍；正文按肤质/需求推荐、每款卖点+价格；**7+图**
- 关键词：日本面膜/面膜怎么选/不踩雷/VC面膜/提亮面膜
- 达人：腰部+头部（造势），KOC跟发

**② B·测评/回购（真人体感·信任）**
- 标题：`回购N次的日本VC精华面膜｜熬夜脸真实测评`
- 体感描述(提亮/服帖/水润)，5–6图；达人：腰部/KOC

**③ C·场景种草（急救/妆前/换季）**
- 标题：`见客户前3分钟急救｜皇后的秘密黑钻VC100`
- 场景化；可图文+**视频**(洼地机会)；达人：KOC/腰部

**④ D·成分党/科普（对高学历人群）**
- 标题：`VC+烟酰胺面膜怎么选｜成分党必看`
- 成分逻辑+对比；达人：成分向博主/中腰部

**⑤ E·比价/囤货（组合装划算）**
- 标题：`日本VC面膜囤货｜79起，划算装分享`
- 突出小红书组合装价；达人：KOC铺量

## 五、⚠️ 合规红线（面膜笔记）
- 避开 **美白/去黄/焕白**（美白需特证）、医疗、极限词 → 改用**提亮/透亮/匀净/水润/服帖**
- 禁站外硬导流（天猫链接/微信）
- 「熬夜急救」是场景不是疗效，可用；但别写「修复受损/治痘」等医疗化表达
