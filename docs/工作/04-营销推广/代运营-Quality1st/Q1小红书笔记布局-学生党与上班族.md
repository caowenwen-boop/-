# 皇后的秘密 · 小红书笔记布局计划（学生党 20+ / 上班族 25+）

- **日期**：2026-11-18
- **用途**：中国笔记方向整合 · 品牌词/推广词锁定 · 年轻向布局
- **主张**：笔记不再跟高年龄直播博主走。面膜是低客单高频品，更大市场是 **20+ 学生党** 和 **25+ 刚上班的上班族**。
- **▼ 假设**：直播间高年龄层能卖囤货，但带不动「平价 3 分钟面膜」的搜索心智；需用笔记验证年轻人群互动与搜索。

> 品牌线：本方案只服务 **Quality 1st / 皇后的秘密**。不混入美康樱森、美纳力、护眼丸。

---

## 一、先说三件事

1. **现状**：直播合作博主偏高年龄；已投笔记偏「日本购物/代购」；品牌写法不统一，黑钻VC100几乎没立住。
2. **判断（▼）**：59–89 元/袋对妈妈/抗老人群不够「值得直播种草」，对学生党和职场新人刚好是「宿舍/工位常备」。
3. **打法**：笔记达人池换成年轻护肤号；品牌词全网锁死；金色走量、黑钻做差异；直播高年龄层继续做囤货，不承担笔记心智。

## 八、怎么判断有没有走对

先行指标（先变这些，再谈成交）：

1. 笔记达人粉丝画像：学生/25–29 占比是否上升  
2. 话题从「日本购物」改到「学生党护肤 / 打工人护肤 / 平价面膜」  
3. 品牌词统一率：正文出现「皇后的秘密」的篇数  
4. 黑钻VC100 被正确写出的篇数（不再写成「黑色」）  
5. 视频占比是否接近 30%  
6. 中位互动是否高于旧 100 篇的 44  

主指标（后看）：相关搜索词排名、加购收藏、天猫年轻客群成交。不要用直播 ROAS 反过来判笔记。
