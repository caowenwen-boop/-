# 12 · 常见问题 FAQ

反复出现、需要快速查阅的问题与标准答案。当某个问题被问到第二、三次，就整理进这里。

## 使用方式
- 每个常见问题建一个文件，或汇整成主题清单。
- 文件名：`主题-FAQ.md`（例：`保税仓入仓-FAQ.md`）。
- 答案要精简、可直接照做；细节可链接到对应分类的详细记录。
