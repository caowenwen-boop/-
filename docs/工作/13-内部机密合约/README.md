# 13 · 内部机密合约 🔒

存放内部机密合约与要点整理。

## ⚠️ 重要：机密保护机制
本文件夹已配置 [`.gitignore`](.gitignore)，**除了本 README 与 .gitignore，文件夹内的所有文件都不会被提交到 git**。

也就是说：
- ✅ 你可以把合约 PDF、Word、扫描件等放进这个文件夹，它们**只保存在你本地**，不会上传到远端仓库。
- ✅ 合约的**非机密要点摘要**若想归档，建议脱敏后放这里，或放对应业务分类。
- ❌ 请勿把合约原件复制到其他会提交的文件夹。

## 本分类收录范围
- 品牌代理/经销合约
- 平台/服务商合作合约
- 达人/MCN 合作合约
- 保密协议（NDA）
- 其他内部机密文件

## 建议的整理方式
1. 合约原件：直接放本文件夹（自动被 git 忽略）。
2. 想做索引：可建一个 `合约台账.md`（同样被忽略，仅本地），登记合约名称、对方、金额、起止日、关键条款、到期提醒。
3. 需要 AI 协助分析合约条款时，把内容贴给 AI 即可；归档时注意脱敏。
