# 02 · 跨境电商政策与法规

跨境电商相关的政策、法规、通关与备案，是日系品牌进中国的合规基础。

## 本分类收录范围
- **跨境模式**：保税仓进口、海外直邮、一般贸易的差异与适用
- **税务**：跨境电商综合税、行邮税、年度/单次交易限额
- **正面清单**：可跨境进口的商品目录
- **通关清关**：三单合一（订单/支付单/物流单）、卡关处理
- **产品备案 / 注册**：
  - 化妆品：普通/特殊化妆品备案、NMPA
  - 食品/保健品：蓝帽子、进口食品标签
  - 其他日系常见品类的准入
- **法规变动**：政策更新、口岸公告
