# 日本自由贩卖资格（自由販売証明書 / Certificate of Free Sale, CFS）模板参考

> 用途：向中国出口（跨境/一般贸易、自由贩卖资格备案）时，部分口岸/收货方要求提供出口国出具的
> 「自由贩卖证明」，证明**该产品在日本合法制造并在日本国内正常流通销售**。
> ⚠️ CFS **不保证某一批次的安全性**，只证明"在日本能自由销售"。
> 最后更新：2026-10；提交前务必以厚労省/粧工会/宁波海关最新口径为准。

## 一、分品类的签发路线（现行）

| 品类 | 对应产品 | 签发路线 |
|---|---|---|
| **食品 / 健康食品** | Sakuranomori 护眼丸、鱼油、hgmi 代餐等 | ① **厚生劳动省·地方厚生局**签发英文 CFS（2013 年起）；或 ② **商工会议所**的"サイン証明"式「自由販売証明書」（对自我声明做签名认证，更快更便宜） |
| **化妆品** | Q1 面膜（DL / DL PRO / TD） | **厚生劳动省**经行业团体 **日本化妆品工业会（粧工会，原日本化粧品工業連合会）**签发「輸出用化粧品の証明書」。**不是**都道府县（旧做法）；2026 年起推电子签发 |

**先决动作**：先向中国进口商 / 宁波海关确认——要"厚労省版"还是"商工会议所版"，是否接受 Apostille。

## 二、对华使用的认证链（2023.11 更新）

**2023 年 11 月 7 日起中国加入海牙《取消认证公约》(Apostille)**：
- 日本签发的公文书，只需在**日本外务省办 Apostille（附加证明书）**，即可在中国使用，
  **不再需要中国使领馆的领事认证**（在日中国使领馆领事认证业务已停办）。
- 政府机关（厚労省）直接签发 → 外务省 Apostille 即可。
- 商工会议所 / 自我声明类（私文书性质）→ 一般需 **公证役场公证 → 法务局 → 外务省 Apostille**。
- ⚠️ 中国各口岸对 Apostille 的受理仍在磨合，**提交前与收货方/海关确认**接受 Apostille 还是旧的领事认证。

## 三、模板①：食品 / 健康食品 CFS（英文，厚労省地方厚生局 或 商工会议所式）

```
                       CERTIFICATE OF FREE SALE

This is to certify, not pertaining to a particular production lot or export
consignment, that the under-mentioned product(s) have been manufactured in
Japan in accordance with the Food Sanitation Act of Japan, and are freely
manufactured, distributed and sold in Japan without any restriction.

   Manufacturer / 制造商   : ______________________________________
   Address / 地址          : ______________________________________
   Product name / 产品名    : ______________________________________
   Dosage form & spec / 剂型规格 : ________________________________
   (成分明细可另附 Annex / Composition may be attached as an Annex)

   Place / 签发地 : ________________   Date / 日期 : ________________

   Issuing Authority / 签发机关 : ____________________________________
   Signature & Official Seal / 签名及公章 : __________________________
```

## 四、模板②：化妆品「輸出用化粧品の証明書」（厚労省 经 粧工会）

> 面膜走这条线，**不自拟格式**——向 **日本化妆品工业会（粧工会）**申请，由厚生劳动省制作证明书。
> 官方样式包含要素（供备料参考）：

```
   輸出用化粧品の証明書（証明書番号：______）

   製造販売業者名 / Marketing authorization holder : ____________
   住所 / Address                                   : ____________
   製品名 / Product name                            : ____________
   該当法令 / Applicable law : 医薬品医療機器等法（薬機法）
   証明文 : 上記製品は日本国において薬機法に基づき適法に製造販売
            （販売）されていることを証明する。

   年 月 日   厚生労働省（経 日本化粧品工業会）
```

## 五、申请前要备齐的信息清单

1. 制造商正式名称 + 英文地址（与营业执照/许可证一致）
2. 产品名（中 / 英 / 日 三语）
3. 剂型 / 规格（如：丸剂 60 粒/瓶；面膜 7 片/袋）
4. 适用法令（食品 = 食品衛生法；化妆品 = 薬機法）
5. 用途国（中国）、提交机关（宁波海关 等）
6. 是否需要成分表 Annex（中国侧常要求）
7. 需要几份正本 / 是否需 Apostille
